# Boostcourse Data Science Coaching Study

네이버 커넥트재단 부스트코스 데이터 사이언스 코칭 스터디의 학습 기록입니다.
팀장으로 참여해 주차별 미션 진행, 결과 공유, 팀 학습 관리를 맡았습니다.

## 학습 내용

- Python과 Pandas를 활용한 데이터 정리 및 탐색
- 공공데이터 기반 교통사고, 의료기관, 물가 분석
- K-Beauty 해외 온라인 판매 데이터 분석
- 시각화와 분석 결과 공유

## 구성

| 폴더 | 내용 |
| --- | --- |
| `Week_1` | Python 데이터 분석 기초 |
| `Week_2` | 공공데이터 탐색과 지도 시각화 |
| `Week_3` | 팀 단위 분석 미션 |
| `Week_4` | 물가 및 해외 판매 데이터 분석 |
| `data` | 교육 과정에서 사용한 공개 데이터 |

> 현재 실무 역량은 [포트폴리오](https://doyoung-data.github.io/doyoung-portfolio.github.io/)에서 확인할 수 있습니다.
